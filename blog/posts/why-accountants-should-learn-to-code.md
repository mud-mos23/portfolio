After building multiple accounting tools ([FinDash](https://github.com/mud-mos23/financial-dashboard), [FraudShield](https://github.com/mud-mos23/fraud-detection), [AuditFlow](https://github.com/mud-mos23/audit-automatique)), I've seen the gap between traditional accounting and modern accounting.

## The Shift

Routine accounting tasks are being automated:
- Data entry (OCR + AI)
- Reconciliation (matching rules)
- Report generation (templates + APIs)
- Compliance checks (audit rules engines)

What remains: **analysis, judgment, and process design**.

## The Opportunity

Accountants who can code can:
- Build custom reports without IT tickets
- Automate their own workflows
- Design better accounting processes
- Understand the tools they use

## Where to Start

- **Python** for data analysis (Pandas is SQL for accountants)
- **SQL** for querying financial databases
- **APIs** for connecting accounting tools

## The ROI

[JP Morgan's research](https://www.jpmorgan.com/insights/technology/ai-in-finance) shows that finance professionals with coding skills earn 25-40% more than peers without.

I designed [AuditFlow](https://github.com/mud-mos23/audit-automatique) to be accessible to accounting professionals. The PCG rules are documented in the code. You don't need to be a developer to understand them — you need to be curious.

The future of accounting belongs to the hybrid: accountant + coder.
